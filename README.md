# 🐰 Hello-Bun

Welcome to **Hello-Bun**! This project is designed to help students learn and practice navigating the command line using **Git Bash**, while also getting hands-on experience with the standard **GitHub workflow**.
[Boris the Professor](https://boris.robertm.cc/courses/level-2a/week-1)

## 🎯 Learning Objectives

By completing this exercise, you will learn how to:
* Navigate your file system using basic terminal commands.
* Create, edit, and manage files directly from Git Bash.
* Track changes using Git.
* Push local changes to GitHub and collaborate using branches and Pull Requests.
